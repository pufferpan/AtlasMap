# 2026-11-02.export-ui

恢复开始导出时从主窗口大小平滑缩小到右下角导出窗口的动画，时长约 0.76 秒。动画过程中只改变内部卡片尺寸，避免持续调整 Windows 原生透明窗口带来的卡顿；日志、终止与结果按钮继续工作。

隐藏调试入口：导出窗口中按 **F12**，或双击顶部标题区域，显示「调试」按钮。点击按钮显示整台电脑的 CPU 占用、已用/总物理内存和内存占用比例，每秒更新；再次点击收起。关闭导出窗口后停止采样。此功能使用 Windows 原生计数器，无需额外安装监控组件。

本次不修改地图导出、材质转换或 UE 导入算法。当前CollectionRoom完整导出记录在各自 `export-code-revision.json` 中，明确实际使用的代码提交。
