# 灯光换算与贴纸透明

## 灯光：从 UE 的「亮度数字」换成 Blender 的能量

旧版本把 UE 的 `Intensity` 直接当 Blender 能量用（sun 直接赋值、其余乘 0.01），
不同灯具差几个数量级，导出后不是死黑就是过曝。现在按物理量纲换算
（`scripts/official/map_light_photometry.py`）：

| 灯型 | UE 单位 | 换算 | 钳位 |
| --- | --- | --- | --- |
| Directional | lux | `W/m² = lux / 683` | 0.002–120 |
| Point / Spot / Rect | lumen | `W = lm / 683` | 0.002–300 |
| Sky | 倍率（≤50）或 cd/m²（>50） | 倍率 ×0.25；cd/m² ÷ 683 后再 ×0.25 | 0.08–1.5 |

再补三件事：

- **衰减距离**：UE 的 `Radius` 是厘米，转成米写进 `use_custom_distance` + `cutoff_distance`，
  灯泡不会照亮整张图。
- **太阳张角**：`light.angle = 0.53°`，阴影边缘不再是刀切。
- **色彩管理**：视图变换固定 `AgX`，look 依次尝试 `AgX - Medium High Contrast` / `AgX - Punchy`，
  曝光按「太阳优先、天光兜底」算：`key = max(sun, 0.6×sky, 0.02)`，
  `exposure = clamp(-log2(key/3), -4, 2)`。没有太阳的夜图不会被硬拉到 +2 EV 烧白，
  阴天/黄昏也还能看清层次。
- **EEVEE 设置**：导入时打开 `use_raytracing` 与 `use_fast_gi`（GLOBAL_ILLUMINATION）+
  `use_shadows`，室内靠间接光提亮，不再只有直射灯照到的地方发亮。
- **天光强度**：UE 的 SkyLight 倍率不能直接当世界背景强度——0.5 直接写会把整张图冲成灰白、
  阴影糊掉。现在 ≤50 的倍率先乘 0.25 再用，最终钳 0.08–1.5；5000 这种 cd/m² 数值除 683 后再乘。
- 输出 `lights.json` 报告（created / supported / sun_strength / sky_strength / lamp_peak_watt /
  exposure_ev），方便按图微调。

每个灯的 `CastShadows` 会写到 `use_shadow`；地图里想手动调，可以在导出根目录放
`game-lighting.json` 覆盖 `exposure_bias_ev`、`local_highlight_contrast`、
`local_shadow_contrast`、`fog_only_scattering_cap`。

## 贴纸透明：材质档位跟着贴图 alpha 走

导出器的 glb 里所有材质都是 `OPAQUE`，贴纸、贴花、铁丝网这类贴图明明带透明通道，
导进 Blender 就是一块实心板。

现在 `core/split_materials.py` 会在导出校验阶段读每个 glb 的材质与贴图：

- 取 `baseColorTexture`（外部 `../textures/*.png` 或内嵌 bufferView 都支持），缩到 384 px 统计 alpha：
  - 全透明（<2%）或大量半透明（>8%，且不是纯镂空）→ `alphaMode=BLEND`，`doubleSided=true`
  - 其余有透明（α<0.5 的像素过半）→ `alphaMode=MASK`，`cutoff=0.5`
  - 完全不透明 → 保持 `OPAQUE`
- 判定结果写进 `split/material-alpha.json`（每个 glb 改了多少材质、各档位计数），
  重复导出幂等，不会反复改文件。

实测一张中型地图：16 个 glb、148 个材质改档（MASK 103、BLEND 45），贴纸和网格都恢复正确。
