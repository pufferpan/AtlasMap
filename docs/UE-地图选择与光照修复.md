# UE 地图选择与光照修复

进入「进 UE」，在「选择地图」里搜索中文名或英文代号，也可以点「扫描游戏地图」或「使用地图库所选地图」。确认下方显示的地图、文件目录和 UE 关卡后，点击「一键导出到 UE」。

- UE 标题、导出按钮和导航已使用本机 UE 安装包中的 Unreal Engine SVG 标志。
- 「导出基目录」下面按地图代号创建独立目录。切换地图时，UE 资源目录和目标关卡一起更新，旧配置里的 CollectionRoomAuto3 不再作为其他地图的目标。
- 同时读取 `Maps/BuildMaps_HD/<代号>/` 和 `Maps/<代号>/`。多个资源根用逗号传给 dfmap，避免只有第一个根生效。
- 保留原先会被过滤的 Lighting 层，导出几何、装饰及源灯光；排除物理代理、反射烘焙和其他玩法变体。静态分块直接交给 Blender，无需建立目录联接。
- UE 直接读取当前地图的 `lights.json`，还原点光、聚光、矩形光、方向光、天光及雾的位置。灯光支持的颜色、强度、范围、锥角、尺寸和阴影属性一并设置。重复执行不会叠加源灯。
- 没有太阳、天光或天空大气时补充对应环境组件；新建的导入工程启用 Lumen。
- 导出结果没有地图实例、与当前地图不匹配、或没有生成本次完成报告时停止，防止复用旧地图和误报完成。Blender 脚本异常也会停止后续步骤。
- 打包排除 Poppler 的同名 ICU DLL，避免覆盖 Qt 6.12 使用的 Windows 系统 ICU。已在原安装目录完成真实 Qt 主窗口初始化自检。

光照仍有源数据限制：当前 dfmap 不提供原游戏烘焙光照、自定义天空材质、天空立方体、PRT/GI 和完整雾参数。天光会重新捕获场景，雾使用 UE 兼容默认值。这些处理会写入地图导出目录中的 `lighting_report.json`。

验证记录位于 `work/ue_fix_20261101/`：SafeHouse真实导出找到 355 个光照组件，UE 5.4 实测还原了 170 个聚光、111 个矩形光、68 个点光、4 个雾、1 个太阳、1 个天光；重复执行两次后数量一致。`tests/test_ue_export.py` 验证地图联动、中文/代号输入、旧地图拒绝、多个资源根及 GUI 进度线程。
