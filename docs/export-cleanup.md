# 取消或失败后的残留清理

普通地图导出和一键 UE 导出在失败、取消后询问是否删除本次残留。选择默认为“保留文件”，Esc 和关闭对话框也保留。成功时不弹出。

提示显示文件数量、估计占用大小和可展开的文件清单。删除在后台进行；提示尚未处理或清理未完成时，软件暂不启动另一轮导出，避免工作目录重叠。

清理前先记录导出目录的已有文件，结束后整理新增文件。只删除新建且清单生成后未再被修改或替换的文件，保留旧文件、日志、既有 UE 工程配置及其他任务目录。UE 模式还包含本次独立临时工程和目标地图资产目录中的新增文件。被覆盖的旧文件不会删除或回滚；选择保留可继续检查中间结果，选择删除后需要重新导出。

不递归删除用户所选目录，不跟随符号链接或 Windows junction。无法访问、仍被占用、发生变化的文件会保留，清理结果写入任务日志。没有可安全清理的新增文件时，删除按钮不可用。
