# 我的工程与简易模式

启动后进入“一键导出”。选择地图和保存位置，然后点击“一键导出到 UE”。首次使用缺少 Blender 或 UE 配置时会自动展开高级模式，按提示选择程序。配置保存后可关闭高级模式。

“高级模式”是一个 FluentPy 原生开关，统一显示引擎与工程路径、性能模式、进程数量、光照与曝光、准备线程和分步命令，并显示“工具”导航。关闭只隐藏操作，不重置原先的配置。简易界面会显示当前工程和是否使用性能模式。

“我的工程”会查找当前配置附近的旧工程；其他位置可点击“扫描工程文件夹”（当前目录及下两层）或“添加已有工程”。新导出成功后自动登记。记录保存在 `%LOCALAPPDATA%/AtlasMap/projects.json`，并使用文件锁和原子保存。

- 列表显示地图中文名、工程路径、可用状态和备注，可搜索中文名或地图代号。
- 双击或“选择此工程”回到一键导出；可打开 UE 工程或文件夹。
- 修改名称和备注只改变列表信息，不重命名 UE 资源。
- 一个 UE 工程内的多张地图共用一条记录。移动与删除作用于整个工程目录，操作前会显示路径并要求确认。
- 移动后更新当前工程路径；独立的原始导出目录保留。跨盘移动失败时保留错误信息与原目录，不自动清理目标中的部分文件。
- 删除使用 Windows 回收站；回收站不可用会报错，不自动退化为永久删除。
- 导出任务或 UE / Blender 运行时禁止移动与删除；工程内含链接目录或多个 `.uproject` 时也不会直接操作。

引擎、Blender、游戏资源和 .NET 10 仍需在本机准备。单文件 EXE 内置查看器、Python/Qt、固定版本导出器、辅助程序和脚本，首次启动需要解包时间。
