# 导出质量与预计大小

“一键导出地图”和“地图库”提供五档质量：轻量（512）、标准（1024，默认）、高清（2048）、超清（4096）、原始（不限制）。此设置控制指定 导出器的 `--max-tex` 参数，仅改变贴图可用 mip 的选择，不删减模型、灯光、天空和地图分块。超过原始资源清晰度的档位不会凭空增加细节。

UE、Blender、普通导出及性能模式的每个源提取进程都会使用所选档位。高级模式中的命令也同步更新。任务日志记录质量与预计大小，源提取成功后保存 `export-quality.json`，供下次估算参考。

天空 HDR 和原始烘焙载荷继续完整保留，不随普通模型贴图档位降级，因此总体积不会严格按贴图像素面积变化。

质量卡片在简易模式下也可见。选择地图后读取已有源导出统计；没有统计时，点击“更新估算”扫描安装的游戏地图，按扫描结果显示粗略范围。切换地图、目标格式、档位或进程数时更新显示，不会启动实际地图导出。

预计大小分为目标文件/工程新增资源和导出过程建议空闲空间。UE 的数字只针对本次新增地图资源，不代表整个已有 UE 工程。临时空间包含源数据、传输文件、贴图、导入缓存的并存开销，并考虑并行工作目录。

这些数字是规划参考，不是实际大小、硬性空间检查或保证上限：

- 已有源导出：读取几何计数、实例计数、PNG 文件大小与尺寸头；跨档位根据像素面积推算，PNG 压缩率、重复资源和最终容器格式仍会带来差异。读取尺寸不解码整张图片。
- 首次导出：使用地图包字节数、关卡数和文件数给出较宽的经验范围。地图根目录之外的外部引用尚未解析，因此可能出现较大偏差，界面明确标为初估。
- 原始质量：未解析原始 mip 时，暂按最高约 8K 的纹理预算推算，并显示“或更多”；更大的源图、烘焙数据和特殊资源可能超出范围。
- 地图库的按层导出参考整图估算，只导出少量层时实际通常更小。

扫描缓存位于用户目录的 `export-size-inventory.json`，按游戏目录隔离。更换游戏目录后重新扫描；游戏更新后也建议点击“更新估算”。已有的磁盘实时保护、失败原因提示、残留文件清理均继续生效。
