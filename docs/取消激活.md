# 取消激活（2026-11-10）

## 删了什么

| 文件/目录 | 作用 | 现在 |
| --- | --- | --- |
| `core/activation.py` | Ed25519 校验、token 解析、机器码、授权记录 | 已删除 |
| `app/activation.py` | 激活对话框与启动门槛 | 已删除 |
| `assets/activation-public.json` | 签发公钥 + 签发站点地址 | 已删除 |
| `tools/activation_owner.py` | 自己签码的脚本 | 已删除 |
| `tools/activation_web/` | 「激活码签发网页」整套前端（index.html / app.mjs / crypto / 测试） | 已删除 |
| `tests/test_activation.py` | 授权相关用例 | 已删除 |
| `docs/machine-activation.md` | 用户说明 | 已删除 |

## 改了哪里

- `app/__main__.py`：去掉 `require_activation()` 门槛；自检里的 `activation_verified` / `activation_native` / `activation_invalid_blocked` 三项与对应截图一并删除。
- `AtlasMap.spec`：资源清单去掉 `activation-public.json`。
- `tools/package_source.py`：必含清单去掉 `assets/activation-public.json`。
- `README.md` / `README-source.md`：把「机器码激活 + 签发网页」改成「不需要激活」。

## 行为差异

- 启动直接进主窗口；没有激活框、没有机器码、没有到期检查、没有签发站点请求。
- 旧版留下的 `%LOCALAPPDATA%\AtlasMap\activation.json`（或旧目录 `%LOCALAPPDATA%\DFMapViewer\activation.json`）不再读取，留着无影响。
- 导出、扫描、Blender 工程、UE 导入等流程都不受影响。

## 验证

- `python -m unittest discover -s tests` → `Ran 288 tests ... OK (skipped=2)`。
- 用干净的 `LOCALAPPDATA` 起单文件版：直接出现主窗口，没有激活框。
- 源码 `grep -rn "activation\|激活\|机器码"` 只剩本文件、README 的一句说明与 `tools/package_source.py` 的私有文件跳过列表。
