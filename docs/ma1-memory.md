# SpaceCenter Ma1 内存错误修复

2026-11-02.ma1-memory

本机失败日志：`952b9351802b4075b30ff5380528daf8`，源光照与烘焙分块 6/8。
在材质 255/725 附近保存原始 JSON 时，Windows 返回
`System.IO.IOException: 内存资源不足，无法处理此命令。`。

- 将中文资源不足、Windows 8/14/1450/1455 错误和辅助程序的结构化内存标记归入内存失败。
- 性能模式按现有可用物理内存和提交空间限制并发；遇到内存错误，保留本组成功分块，未完成分块改为单进程重试一次。
- 及时释放 GLB、材质继承链、类模板、环境和烘焙引用扫描中的 JSON 文档缓冲区。
- 环境资源扫描不再把内存不足当作普通不支持资源而跳过；错误向上传递以触发重试。

本版本仍使用原始固定版本 导出器，没有修改其二进制。

验证：117 项测试通过。单独复跑原失败的 Ma1 第 6 块，源状态阶段正常退出 0，
完整处理 116 个关卡、725 个材质、926 个资源包、24 个烘焙文件；解码 85 个
HDR 反射立方体，没有不支持的反射文件布局。记录在 `work/ma1-memory-native.log`。
最终发布辅助程序再次处理同一批反射文件，仍为 85 个成功、0 个不支持布局。

以上是失败阶段的针对性验证，尚未完整重跑 Ma1 整图的 Blender 输出和 UE 导入。
