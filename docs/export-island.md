# 顶部导出进度条

导出窗口右上角的“隐藏”会将全部导出窗口动画收拢到当前屏幕顶部中央，留下 340 × 52 的小进度条。普通导出和性能模式都支持；收起过程只缩放缓存画面，原日志窗口的位置、大小保持不变。

收起时窗口内容逐渐模糊，并与顶部进度条交叉淡入淡出；恢复时反向过渡为清晰内容。模糊图像在动画开始前缓存，520 毫秒过渡使用平滑缓动，每帧仅缩放和混合缓存画面。

进度条显示当前步骤、整体进度、用时以及分块数量。单击进度条恢复全部窗口；右侧方形按钮直接终止导出。导出在后台完成时显示绿色成功状态，失败时显示红色状态，单击后恢复窗口查看结果和日志。

首次分窗动画完成后可以收起。关闭导出窗口会同时清理进度条和过渡动画，不留下独立浮窗。
