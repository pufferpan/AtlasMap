# 导出失败原因

导出失败后，小窗口和「任务」页会直接显示失败步骤、分块、原因、处理建议与错误原文。
支持一键复制原因、查看任务日志、导出完整日志。完整日志保存所有分块输出及最终原因，
不受界面 4000 行或历史统计数量限制。其他分块被取消时，会保留最初失败分块的原因。

内存/虚拟内存不足、磁盘空间不足、文件缺失、权限或文件占用、路径过长、
组件加载失败、输出校验和数据损坏分别提示。无法可靠判断的退出会保留原始错误，
明确显示尚未识别具体原因，不把所有退出都解释为内存不足。正常取消不显示失败原因卡片。

重新启动后，会从最新已结束的失败日志恢复原因；成功、取消或仍在运行的日志不会
被当作上次失败。历史日志可继续导出，原文件保持只读。

本次Brakkesh日志显示「模型输出 2/3」写 manifest.json 时抛出 MemoryError。
清单保存已改为流式写入临时文件，写入完成后原子替换，避免 json.dumps 和文本编码
同时生成整份清单的大字符串；写入中断时保留旧文件并删除本次临时文件。
这项修复降低清单写入阶段的内存峰值，其他模型、贴图处理仍受可用内存限制。
