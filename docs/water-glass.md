# 水和玻璃导出修复（2026-11-02）

导出流程通过原版 dfmap 读取材质实例和父材质，保存混合方式、着色类型、透明度范围、折射率、粗糙度及水面法线；原导出工具二进制保持不变。

玻璃使用虚幻薄透明表面光照，平整玻璃采用像素法线偏移折射，连接透明度、法线、镜面和折射输出。水面使用 Single Layer Water 输出和原始法线，保留源参数并记录兼容转换。树叶等镂空材质保持 Masked；水箱等普通模型根据父材质判断，不按模型名称误判成水面。

游戏定制水体模拟、岸边交互和已经裁剪的着色器计算无法原样恢复；吸收/散射单位与波纹运动使用原生引擎兼容实现，不能保证与游戏逐像素一致。原始数据保存在 source-render/materials.json 和 raw 中，兼容参数记录在 surface_report.json、Blender 材质与导出清单中。

已导出的旧文件不会自动改变，请使用新版重新导出。性能模式成功提示保留每个窗口的位置与尺寸，点击成功画面查看各自日志。开启性能模式时，右上角显示可点击关闭的红色引擎浮窗。
