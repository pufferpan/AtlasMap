# 导出完整日志

在导出窗口或「任务」页面点击「导出完整日志」，选择保存位置，可保存为 `.txt` 或 `.log`。
任意分块窗口的按钮都会保存整次任务，包括主流程和全部分块的 Blender、UE 等子进程输出。

完整记录不受界面显示行数及噪音过滤限制，包含任务版本、开始时间、命令与步骤、
时间戳、进程输出、异常堆栈和最终退出码。运行中保存的是点击保存时刻的快照；
结束后可再次保存最终日志，原有的「复制日志」仍可复制当前窗口文字。

每次任务的原始日志自动保存在：
`%LOCALAPPDATA%\AtlasMap\logs`

成功、失败和取消都会保留日志；导出失败或取消后清理地图残留文件不会删除此处的完整记录。
重新启动软件后，历史日志仍可在上述目录找到。

日志记录和文件保存失败时会显示错误，不会把不完整记录当作完整日志导出。
