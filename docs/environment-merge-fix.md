# 并行环境贴图汇总修复

BombDefusal_Watch 与 Dam_Iris_Long3 的近期日志均在第 8 步“汇总渲染状态”报出“同一环境资源在分块间不一致”。同一张源环境贴图可能被不同关卡中的反射捕获对象引用，分块报告中的 `selection_basis` 因此不同；这属于引用来源差异，不代表贴图或渲染参数不同。

合并现在单独保留所有引用来源：`selection_bases` 为排序去重后的来源列表，`selection_basis` 保留一个稳定的兼容值。其余字段仍严格比较，包含贴图身份、尺寸、类型、eligibility、亮度及其他渲染参数。每一个重复记录的实际贴图文件也必须存在，并与汇总文件逐字节一致，避免仅凭 JSON 一致就略过损坏或缺失文件。
