# 只导出选中的区域

一张地图动辄几百个分块、几个 GB。只要某条街、某个楼，就用「只导出选中区域」。

## 怎么用

1. 主界面「一键导出」→ 勾上 **只导出选中区域** → 点旁边的 **框选…**。
2. 弹出的对话框里会画出这张图的平面图：每个方块是一个 `split` 分块（`split/manifest.json` 里的
   `ueBoundsMin/ueBoundsMax`），方块越大说明那一块东西越多。
3. 在图上拖一个矩形，或在下面直接填 X/Y 的最小最大值（单位厘米，跟导出器一致）。
4. 点「用这个范围」。想取消就点「清除区域」。

## 裁剪口径

- 导出器不提供任意多边形裁剪，所以范围是**按分块**裁的：分块包围盒与你的矩形相交就整块保留，
  不相交就删。边界会多带一点几何，不会把建筑切成两半。
- 删掉的是 `split/<分块>.glb`，同时重写 `manifest.json` 的 `levels` 与 `totalVertices`，
  并写 `region-report.json` 记录保留/移除的块数与节省的字节。
- Blender 和 UE 两条链路都是从这里读分块，所以两边都只拿到选中的几何。

## 第一次用为什么是空的

平面图来自上一次整图导出的 `split/manifest.json`。新地图、新目录还没有这个文件，
对话框会提示「先整图导一次」，这时可以直接在下面填坐标，或者先整图导一遍再回来框。

## 命令行

区域也会传给 Blender 导入脚本：

```bat
set ATLASMAP_REGION=1000,-21000,6000,-14000
```

或 `--region x0,y0,x1,y1`（UE 厘米）。脚本里按 `matrix_world @ bound_box` 与区域求交，
不相交的物体直接移除，再写一份 `region-report.json`。
