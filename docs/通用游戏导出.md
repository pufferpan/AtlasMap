# 导出其他游戏的单张 .umap

Delta Force 那条「一键导出」有固定目录约定；别的游戏没有，所以单独做了一个
**其他游戏…** 对话框（一键导出页 →「选择地图」右边）。

## 前提

1. 游戏目录里有 `Content/Paks`（选游戏根目录也行，会自动往下找）。
2. 知道引擎大版本（默认 `GAME_UE5_3`，可在下拉里改）。
3. 如果 pak 加密，需要 32 字节 AES 密钥（64 个十六进制字符）。

## 流程

1. 选游戏目录 → 状态栏显示找到的包目录。
2. 点「检测 / 填密钥」：
   - 程序用 `probe` 列一遍归档，报告每个包是否加密、有没有挂上；
   - **每有一个加密包就问一次密钥**（GUID 全零的多个包共用一把主密钥）；
   - 填完后自动再探一次，确认挂载成功。
3. 点「列出地图」拿 `.umap` 列表（`find .umap`，去重）。
4. 选一组输出目录和一张地图，点「开始导出」：
   - 导出器写出 `split/*.glb`、`manifest.json`、`lights.json`；
   - 若设置里配了 Blender，顺带用 `blender_iceland.py --flat-split` 生成
     `scene_no_terrain.blend`，可以直接打开。
5. 产物目录里还会留 `export.log` / `blender.log`，失败时先看这两个。

## 限制与说明

- IoStore（`.ucas/.utoc`）游戏能不能挂，取决于 CUE4Parse 的版本支持；老引擎
  （如 UE4.27）会尝试解析，缺 `LoaderGlobalNameHashes` 时会报错退出。
- 没有密钥文件也能探测：程序现在只提示「只有未加密的包能挂」，不再直接报
  `FileNotFoundException`。
- 导出的地图不含地形（`scene_no_terrain.blend`），和 Delta Force 那条一致。
- 密钥只写在本机 `%LOCALAPPDATA%\AtlasMap\generic\keys.json`，不上传。

## 单张 .umap 导不出几何时

UE 的关卡经常把实际内容放在同目录的子关卡里，主 .umap 自己几乎是空的。
所以工具会先只按你选的那个文件导出；如果 `split/manifest.json` 里一个实例都没有，
自动退回「整个目录」再导一次，日志里会打一行：

```
[generic] 单文件没有实例，已改用上级目录重新导出：
```

这样既能精确导单张图，也不会出现「导出来是空场景」的困惑。

## Blender 导入失败时

对话框会把 `blender.log` 最后几行直接显示出来，并给出完整日志路径。
常见原因：
- 这台机器上 Blender 版本太老（脚本用到 4.x 的 API）；
- 场景里没有任何网格（先看导出日志有没有 `levels found` / `instances`）；
- 材质修补在别的游戏上不适用 —— 现在会跳过并继续保存几何，不再整段失败。

## UE5 游戏为什么常常「挂载成功但导不出东西」

UE5 的 cooked 包用的是 **unversioned property**（属性不带类型信息），读 actor 时需要一份
`.usmap` 映射文件把名字和类型对上。没有映射时 CUE4Parse 会抛：

```
MappingException: Package has unversioned properties but mapping file is missing, can't serialize
```

表现出来就是：包能挂载、`.umap` 能列出来，但每个关卡都是 `0 instances`，最后 Blender 报
`No meshes imported`。Delta Force 不需要映射，因为导出器内置了它的类型表（`DeltaForceTypes`）。

### 怎么给它映射

1. 把该游戏的 `.usmap` 放到这三个位置之一：`Paks` 目录、`Paks` 的上一级、或其中的
   `Mappings/`、`usmap/` 子目录 —— 导出器会自动挑体积最大的那个。
2. 或者在「导出其他游戏的 .umap」对话框里用「映射文件（.usmap，可选）」直接选文件。
3. 选了文件但格式不对时，日志会打 `[atlas] mappings failed to load '…': Usmap has invalid magic`。

`.usmap` 一般由 FModel / UsmapGenerator 这类工具从游戏本体里 dump 出来，和游戏版本、引擎小版本强绑定；
版本不对会解析出乱码或直接崩。没有映射文件的 UE5 游戏，只能列地图、导不出几何。
