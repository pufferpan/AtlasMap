# 机器码激活

版本：`1.0+2026-11-04.machine-activation`

软件启动时先校验本机激活记录。首次运行、记录损坏、签名无效或机器码不匹配时显示激活窗口；正确激活后才能进入开屏、首次向导和主界面。跳过开屏和程序自检模式同样需要有效激活。

## 使用者

1. 启动新版软件，点击「复制机器码」。
2. 将机器码交给软件提供者，获取激活码。
3. 粘贴完整的 `DFMA1.` 开头激活码，点击「激活并启动」。之后可离线使用，不需要每次输入。

机器码来自 Windows MachineGuid 的单向摘要，不包含明文系统标识。授权长期有效，绑定当前 Windows 安装；重装系统、换电脑或复制激活记录到其他设备，需要用新机器码重新签发。

## 管理者

私人签发网页：<https://dfmap-activation-console.jfding-ecnunic.chatgpt.site>

仅网站所有者可访问。每次打开网页先选择配套 `owner-signing-key.pem`，之后粘贴机器码即可自动生成激活码；也可复制或保存文本。私钥只在当前浏览器页面的内存中使用，不上传服务器、不保存在浏览器存储；锁定或刷新后需重新选择。

配套私钥首次创建时保存于本机「文档」中的 `AtlasMap-Activation` 文件夹，独立于工程及发布包，并限制为当前 Windows 用户访问。请单独备份；不要发给软件使用者。遗失后无法为当前软件公钥签发新激活码。软件、网页、公开配置与发布包只包含公钥。

离线命令行备用工具为 `tools/activation_owner.py`：

```powershell
python tools/activation_owner.py issue --private-key <私钥路径> --machine <机器码> --out 激活码.txt
```

签名使用标准 Ed25519，桌面端通过 cryptography 校验，网页通过 Web Crypto 生成。校验包括签名、产品、格式版本、机器码与规范化数据；复制其他电脑的记录、修改激活码或使用另一把密钥均不能通过。

本机激活记录保存在 `%LOCALAPPDATA%/AtlasMap/activation.json`。这是一套离线授权校验，不提供在线撤销，也不声称能够阻止对客户端程序的修改。
