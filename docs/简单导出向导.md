# 简单导出向导

第一次用不用啃设置页。点「一键导出」时会先问一句：

- **用向导**：四步走完直接开跑
- **直接导出**：用当前设置（老用户走这条）
- **以后不再询问**：记进设置 `wizard_never`，想恢复就在设置页点「重看首次向导」，或删掉
  `%LOCALAPPDATA%\AtlasMap\settings.json` 里的 `wizard_never`

## 四步

1. **选地图**：下拉里是扫描到的全部地图，显示 `显示名 (代号)`，可以直接搜。
2. **保存位置**：导出根目录，Blender 工程放在 `<根目录>_blender/<run>/`。
3. **精度**：标准（1K 贴图）/ 高清（2K）/ 原始（不缩）。右侧给出预估大小，说明是历史实测还是估算。
4. **区域**：整张图或框选一块（见 `docs/区域导出.md`）。

点「开始导出」后：先把选择写回主界面控件并保存设置，然后走原来的导出管线
（校验 → 导出 → Blender/UE → 校验报告），向导本身不复制一套导出逻辑。

自动化/无头环境（`QT_QPA_PLATFORM=offscreen`）或设了环境变量 `ATLASMAP_NO_WIZARD=1` 时不弹这个询问。
